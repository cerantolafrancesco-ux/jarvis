## Pattern emersi
> Pagina bianca + popup-terminale (uno per interazione), FAB `+`, finestre vetro spostabili/ridimensionabili. Estetica "Aqua" anni 2000: onde, suoni acqua, trasparenza dinamica all'overlap, tab-bolle trascinabili, titoli che evolvono (riassunto LLM della sessione). È il front-end della visione "interfaccia unica che instrada su Chat/Cowork/Code".
